═══ NEW LAWS (P7) ═══
  1. *** THE SILENT-NO-LAUNCH LAW ***: MG._build does (grid+(1,))[:3] for
     tuple grids — a 1-TUPLE grid becomes a malformed 2-tuple global_size
     and the graph NEVER EXECUTES, SILENTLY (top1=0 = the output buffer
     never written; a later graph's output reads as stale-correct and
     masks it). L56's _grid normalizes 1-tuples to scalars — any seq
     builder MUST do the same. This bit EVERY P7 graph on first contact
     (the mock-vs-rig meta-law again: the harness-side builders were
     never exercised at scale).
  2. THE FULL-SYNC COPY LAW: allocator _copyin/_copyout each do a FULL
     dev.synchronize() — the P6 ~14ms host path was 6 of these. The
     cpu_view() fold (cpu_access=TRUE + **uncached=TRUE** sysmem buffers,
     monkeypatched through NVAllocator._alloc which DROPS the flag) is
     bidirectionally coherent (120/120 + the graph paths) and FREE
     (VRAM-vs-syssem A/B identical). cpu_access WITHOUT uncached maps
     VRAM GPU_CACHEABLE_YES — the stale-read race class (do not use for
     per-cycle control).
  3. THE GPU-EXIT LAW EXTENDED: the GRACEFUL socket shutdown (bye:true)
     ALSO reboots the machine (2/2 tonight, 6/6 lifetime) — the disable-
     first + sudo-sync dance is MANDATORY (an unsynced launchctl disable
     is LOST to the reboot — bit us once).
  4. SPLIT-S NUMERICS CLASS: split attention at S != S' differs from
     itself (~7e-2 state maxdev over 256 tokens) — same-S is bit-exact.
     Anchors and engines MUST pin the same S per phase (F1's original
     "state DIFF" was the S=32-vs-S=8 arm mismatch, not a chain bug).
  5. THE WARP-PER-POSITION PATTERN: replacing the 2-__syncthreads-per-
     position score loop with warp-per-position (lane l owns dims l*8..+7)
     removed the spkq O(L) wall — 4x at L=16k P=1, more at P=1/64k decode.
  6. THE 16GB RAM WALL at the 96k anchor: the CPU split-anchor at R=98304
     + snapshots + the GPU harness process hit 16.2G RSS + 4.5G swap —
     the ladder survived but thrashed (~1h for L96). The fix path: free
     KV0 after first-64, stream the rebase, or shrink the expert LRU.
  7. TEST-DESIGN LAWS (three gate bugs found by re-examination, all in the
