## 2. THE DISCRIMINATOR CORRECTION (the headline finding)

The P8 commit's "x4.58 (266.6us vs 1220.3us)" compared ONE W plane at M=64
g=272 against the census's TWO-plane M=128 g=1088 launch. Per fp16
unit-of-work (one plane, one M-block) = 1220.3/4 ~= 305us -> the true IMMA
advantage at these shapes is **x1.1-1.15 standalone**, x1.06 fused-with-full-
decode (v2), x1.56 fused-with-free-nibbles (v1). The W-stream saving (19% fewer
bytes) is small; the decode/rescale chain (per-32k-group scales!) eats the
rest. **W4A8 IMMA at prefill GEMM shapes is a ~1.0-1.6x class on this dext,
not a 4.6x class. 750 via Tier-2 W4A8 is dead; the +7.3% v2 ship is the real

## 5. LAWS banked this campaign

1. *** P.poison BYTES-vs-ELEMENTS ***: P.poison(name, NBYTES, dtype, val) —
   passing element counts for f32/i32 buffers under-sizes 4x -> OOB STG ->
   SM fault (cost a fault-storm afternoon dressed as a "4-arg launch law";
   the red herring is documented below).
2. *** THE TERNARY-NEGATION INT-SHIFT PACKING LAW ***: composing packed s8
   via `((int)(signed char)(neg ? -l : l) << 8j)` CORRUPTS bytes 1-3
   (attenuation ~2^-j per byte — only-negative values wrong); explicit
   two's-complement byte composition (`(unsigned char)(256-level)`) is
   exact. Isolated by a mixing-matrix probe (single-k xq vectors regressed
   against all predicted W columns).
3. THE PER-WORD SCALE LAW: the fork's IQ3_XXS db exponent (sw>>28) is PER
   32-k SCALE-WORD, not per 256-block — any fused decode must rescale per
   k-32-group (the mma k-step granularity conveniently equals it).
4. THE IQ3 GRID IS 8 LINEAR LEVELS: [4,12,20,28,36,44,52,62] — an int4
   linearization at delta=4.0507 costs only 1.49% weight-RMS (8.4x better
   than a raw int4 requant). IMMA-on-packed7 is therefore numerically cheap.
5. The char4/make_char4 store codegen faults this dext while the identical
   hand-packed int STG is clean (kept the int form; 4-arg launch faults were
   the poison bug, not args).
6. VRAM wall measured: the full-100k-state headroom < 1.9 GB (a 1.93 GB
   plane upload faults mid-copyin; 1.2 GB fits) — any new-plane port is
   partial-coverage-only. The G3M budget pattern (fallback to packed7) is
   the right structure for such ports.
7. The discriminator-frame lesson: per-launch speedup claims MUST match
   plane-count and M-grid between arms (one-plane-M64 vs two-plane-M128
   inflated x1.15 -> "x4.58").
